# Kids English Videos - 3岁宝宝英语启蒙系列

> Wow English 风格的儿童英语教学视频，专为2-4岁宝宝设计

| 集数 | 主题 | 核心词汇 | 文件 |
|------|------|---------|------|
| EP01 | Fruit & Food | apple, banana, milk, egg, orange, cake | `videos/kids_fruit_food_english.mp4` |
| EP02 | Animals (Pets) | dog, cat, bird, fish, rabbit, mouse | `videos/kids_animals_pets_english.mp4` |

## 📋 系列规划

完整规划文档请见 [3岁宝宝英语学习系列规划.md](./3岁宝宝英语学习系列规划.md)

共 4 个 Level、24 集，涵盖基础词汇 → 日常扩展 → 动词形容词 → 简单句型的递进式学习路径。

## 🎬 视频规格

- **时长**：每集约 5 分钟
- **分辨率**：1920×1080 (Full HD)
- **帧率**：20fps
- **配音**：en-US-JennyNeural (慢速15%)
- **字幕**：内嵌英文 ASS 字幕
- **背景音乐**：程序合成的 C-G-Am-F 循环配乐

## 🏗️ 单集结构

```
片头(20s) → 词汇展示(60s) → 拼写跟读(60s) → 互动游戏(60s)
→ 拓展环节(30s) → 复习回顾(30s) → I Like(20s) → 片尾(10s)
```

## 💡 使用建议

- 每天5分钟，固定时间观看
- 家长陪同观看并一起跟读
- 鼓励孩子用肢体动作配合（TPR）
- 每周1集新内容 + 1集旧内容复习
